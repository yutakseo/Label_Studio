# 마스크 라벨링 사용법

## 프로젝트와 태스크 준비

1. 서버에 로그인해 프로젝트를 생성합니다.
2. Settings의 Labeling Interface에 데이터셋 XML을 적용합니다. 여러 라벨을 사용할 때 각 Label을 BrushLabels 안에 등록합니다.
3. 데이터셋 `tasks.json` 또는 분할 import JSON을 가져옵니다. Local Files 저장소로 등록할 수도 있습니다.
4. 이미지가 보이지 않으면 [files 문서](../files/README.md)의 URL 기준 경로를 확인합니다.

```xml
<View>
  <Image name="image" value="$image"/>
  <BrushLabels name="brush" toName="image">
    <Label value="Exposure"/>
    <Label value="Weldline"/>
  </BrushLabels>
</View>
```

## 수동 편집과 저장

브러시·지우개는 최소 0.2px, 이후 0.5px 단위로 최대 30px입니다. 이미지 좌표를 0.1px 격자로 맞추고 사각 도장을 연결합니다. 태블릿 펜의 누르기·이동·떼기도 편집기에 연결합니다. 최종 PNG 해상도는 원본 크기입니다.

**Update/Submit**으로 저장한 결과를 내보내기 대상으로 사용합니다. 자동 저장은 미제출 초안이므로 Export 전에 제출해야 합니다. 다른 사용자의 라벨을 수정하면 본인 작업 라벨로 저장하고 다른 작성자의 원본은 보존합니다. 본인 작업 탭은 갱신하며, 별도로 만든 MERGE 탭은 일반 작업 탭과 구분합니다.

탭에는 저장 작성자와 마지막 수정 시각을 표시합니다. 작성자가 없는 가져온 라벨은 작성자를 추정하지 않습니다. 결과를 실제 변경해 저장하면 저장 사용자에게 귀속됩니다. 탭은 수정 시각 오름차순으로 표시하고 기본 선택은 최신 저장 결과를 기준으로 합니다.

## 보조 도구 선택

| 상황 | 도구 | 저장 방법 |
| --- | --- | --- |
| 유사 밝기의 연결 영역을 지우거나 추가 | 매직 브러시 | 현재 편집 → Update |
| 어두운 영역을 임계값으로 일괄 제거 | 배경 마스크 후처리 | 미리보기 → 새 어노테이션 |
| 원본과 블러 차이로 후보 생성 | 가우시안 마스킹 | 선택 영역에 적용 → Update 또는 별도 저장 |
| 기존 Exposure 모델 후보 | U-Net pseudo 라벨링 | U-Net 예측 탭 저장 |
| 클래스별 수정 사례를 누적 | 참고 마스크 학습 | 패치 학습 → 전체 미리보기 → 클래스 예측 탭 |

자동 검출은 후보입니다. 시편 경계·질감·정상 밝기 변화도 검출될 수 있으므로 원본과 비교합니다. 도구별 미저장 편집 반영 여부는 해당 확장 README에 명시되어 있습니다.

## 참고 마스크 학습

이미지 툴바에서 참고 마스크 학습을 열고 라벨을 선택합니다. 현재 태스크의 본인 저장 마스크를 초기값으로 가져옵니다. 64×64 ROI에서 해당 결함만 칠하고 학습합니다. 아무것도 칠하지 않은 음성 패치도 학습할 수 있습니다. 현재 코드는 학습 버튼마다 저장된 수정 패치로 20스텝 추가 학습합니다.

같은 클래스의 패치는 여러 이미지·참여자 사이에서 누적됩니다. 클래스가 바뀌면 모델과 패치 저장 공간도 바뀝니다. 각 클래스는 독립 이진 모델이며 겹침을 자동 해소하지 않습니다. 새 라벨 추가에는 프로젝트 설정 변경 권한이 필요합니다. 자세한 모델·공유·이전 정책은 [Reference Segmenter](../label_studio/third-party/reference_segmenter/README.md)를 확인하세요.

## 서로 다른 라벨의 마스크 합치기

1. 편집 중인 내용을 먼저 저장합니다.
2. 툴바의 **마스크 합치기**를 엽니다.
3. **대상 이미지 · 라벨 → 모든 라벨 유지**를 선택합니다.
4. 가져온 라벨, 사용자 저장 라벨, U-Net/Reference 예측 중 2~32개 탭을 선택합니다.
5. **미리보기**에서 결과와 라벨 목록을 확인합니다.
6. **새 라벨로 저장**을 누르고 창을 닫은 뒤 새로고침합니다.
7. 새 **MERGE** 탭에서 라벨별 결과를 확인하고 편집합니다.

같은 라벨은 합집합으로 묶고 서로 다른 라벨은 별도 브러시 영역으로 유지합니다. 라벨이 겹친 픽셀은 양쪽에 모두 남습니다. 미리보기 겹침 위치에서는 나중에 그려진 라벨 색이 앞에 보일 수 있지만 저장 RLE에서는 양쪽 마스크를 유지합니다. 특정 라벨만 선택하면 그 라벨만 합칩니다. 원본 탭은 변경하지 않습니다.

선택 원본이 저장 전 변경되었거나 태스크가 바뀌면 저장을 중단합니다. 미제출 초안은 대상이 아니며, 동일 크기·회전 없는 RLE 마스크만 지원합니다.

## 내보내기

프로젝트 **Export → 폴더 구조 유지 · PNG 마스크 + 원본 (ZIP)**에서 라벨을 고릅니다. 이 기능은 프로젝트 전체를 내보내며 데이터 매니저의 필터·선택 행을 적용하지 않습니다.

태스크마다 취소되지 않은 저장 annotation 중 마지막 수정 시각과 ID 기준 최신 하나를 사용합니다. 최신 결과에 선택 라벨이 없으면 빈 PNG입니다. 초안과 예측은 제외합니다. 여러 클래스가 한 MERGE 결과에 있더라도 PNG는 선택한 한 라벨의 이진 영상이고 전체 결과는 `_annotations` JSON에 보관합니다. 클래스별 PNG가 필요하면 라벨을 바꿔 각각 다운로드합니다.

ZIP의 `export-manifest.json`에서 포함·건너뜀 내역을 확인하세요. 이미 내려받은 파일은 이후 저장 내용을 자동 반영하지 않으므로 다시 다운로드해야 합니다.
