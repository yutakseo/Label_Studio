# U-Net 재학습 결과

기존 활성 가중치와 직전 백업을 제거하고, 기존/사전학습 가중치 없이 U-Net을 무작위 초기화했습니다.

- 데이터: 전체 이미지·마스크 12쌍 + 수정 패치 10쌍 = 22쌍
- 파라미터: 7,849,025개
- 학습: AdamW, 학습률 0.0003, 배치 8, BCE+Dice, 1,500 optimizer steps
- 선택된 가중치: 고정 검증 패치 평가가 최상인 700스텝
- 검증 이미지: 946, 949. 수정 패치가 있는 947은 제외
- 임계값: 0.5

| 지표 | 이전 500스텝 | 새 모델 |
|---|---:|---:|
| Dice | 84.91% | 89.10% |
| IoU | 73.77% | 80.35% |
| 정밀도 | 88.52% | 88.08% |
| 재현율 | 81.58% | 90.15% |

초기 사전학습 기반 300스텝 모델의 같은 2장 Dice 90.81%보다는 낮습니다. 검증 이미지를 가중치 선택에도 사용했으므로 독립 테스트 결과는 아닙니다. 동일 프로젝트 내 2장 평가이며 다른 시편의 성능을 보장하지 않습니다.

새 모델을 활성 체크포인트 경로에 적용했습니다. Label Studio 예측/어노테이션 DB는 변경하지 않았습니다. 상세 지표는 report.json, 학습 데이터 명세는 manifest.json에 있습니다.
