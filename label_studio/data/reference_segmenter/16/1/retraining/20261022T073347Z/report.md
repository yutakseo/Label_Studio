# 패치 전용 U-Net 재학습 결과

학습: 직접 수정한 64×64 패치 28쌍만 사용. 무작위 초기화, 전체 이미지/사전학습 가중치 사용 안 함.
추론: 64×64 패치, stride 32, Hann 확률 가중 평균 후 원본 해상도로 복원.
학습 시도 1500스텝 중 전체 이미지 검증 Dice가 최상인 400스텝을 적용.
검증은 학습과 겹치지 않는 946·949번이며, 검증 이미지의 역전파는 수행하지 않음.

| 지표 | 현재 패치 전용 모델 |
|---|---:|
| dice | 61.55% |
| iou | 44.46% |
| precision | 57.62% |
| recall | 66.07% |

이전 전체 이미지 혼합 학습 모델 Dice 89.10%보다 낮음. 현재 28개 수정 패치만 사용한 모델의 검증 결과임.
검증 데이터로 모델도 선택했으므로 독립 테스트 성능은 아님. 다른 시편의 성능을 보장하지 않음.
기존 전체 이미지 12쌍은 excluded_full_images/로 이동해 학습에서 제외. DB 예측/어노테이션은 변경하지 않음.
